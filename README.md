# `# Репозиторий документации СМИБ` 

# `## Назначение` 

```
Репозиторий предназначен для ведения документированной информации
системы менеджмента информационной безопасности (СМИБ) учебного объекта.
```

# `## Структура каталогов` 

- ``01-politika/` — политика ИБ верхнего уровня` 

- ``02-chastnye-politiki/` — частные политики` 

- ``03-procedury/` — процедуры и регламенты` 

- ``04-instrukcii/` — инструкции, шаблоны, чек-листы` 

- ``05-zapisi/` — шаблоны записей` 

# `## Порядок внесения изменений` 

`1. Создать ветку с осмысленным именем.` 

`2. Внести изменение.` 

`3. Зафиксировать коммитом с описанием причины.` 

`4. Создать запрос на слияние с рецензентом.` 

`5. После одобрения рецензента — выполнить слияние.` 

`6. Пометить утверждённую редакцию тегом.`
